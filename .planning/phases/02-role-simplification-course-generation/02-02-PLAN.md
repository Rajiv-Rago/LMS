**GREEN phase -- implement endpoint** (`app/api/courses/generate/route.ts`):

Follow the code example from 02-RESEARCH.md exactly:
1. CSRF check via `requireCsrf(request)`
2. Authenticate via `authenticate(request)` -- no role check (ROLE-01)
3. Validate body with Zod schema: `{ topic: z.string().min(1).max(500), skillLevel: z.enum(["beginner", "intermediate", "advanced"]) }`
4. `await dbConnect()`
5. Check 5-course limit: `Course.countDocuments({ owner: user.userId })` >= 5 returns 429
6. Rate limit: `enforceAIRateLimit(user.userId, tier, "credits")` -- use `user.role === "admin" ? "admin" : user.subscriptionTier` for tier (note: subscriptionTier may not exist on JWTPayload, use a fallback like `"free"`)
7. Provider check: `resolveProvider({})` returns null means 503
8. Enqueue job: `enqueueJob({ type: "ai.generate-syllabus", data: { topic, targetLevel: skillLevel, estimatedDuration: "4-6 hours", includeVideos: true }, userId: user.userId })`
9. Return `{ jobId }` with 202
10. Wrap in try/catch, captureException on error

Keep MAX_GENERATED_COURSES as a module-level constant (easy to change later per user decision).
