Chips: "Python for Beginners", "Web Development Basics", "Data Science Fundamentals", "Machine Learning 101". Clicking a chip fills the topic input.
   - Control whether to show the welcome/chips via a `showWelcome?: boolean` prop.

   - "use client" component
   - Props: `{ topic: string; onCancel?: () => void }`
   - Card showing: "Generating your course on '{topic}'..." with an animated spinner (`animate-spin`)
   - Subtle gradient border or background using the AI gradient (`from-indigo-600 to-violet-600`)
   - Dark mode support

3. **CourseSection component** (`components/dashboard/CourseSection.tsx`):
   - "use client" component
   - Props: `{ title: string; courses: Course[]; emptyMessage?: string }`
   - Renders a section header (h2) and a responsive grid of course cards (3 cols on lg, 2 on md, 1 on mobile)
   - Each card shows: title, progress bar (% lessons completed if available), lesson count
   - Cards link to `/courses/{courseId}`
   - Empty state: shows `emptyMessage` text in a muted style
   - Dark mode support
   - Progress-focused: show "X/Y lessons completed" and a visual progress bar

4. **Dashboard page** (`app/(dashboard)/dashboard/page.tsx`):
   - Full rewrite. Remove ALL role-based conditionals (`user.role === "teacher"`, teacher stats, etc.).
   - State: `generationPhase: "idle" | "submitting" | "generating" | "complete"`, `generatingTopic`, `myCourses`, `enrolledCourses`, `loading`, `courseCount`
   - On mount: fetch both course lists in parallel with `Promise.all`:
     - `GET /api/courses/ai/my-courses` for generated courses
     - `GET /api/courses?enrolled=true` for enrolled courses
   - Render `GenerationInput` at top (with `showWelcome={myCourses.length === 0 && enrolledCourses.length === 0}`, `limitReached={courseCount >= 5}`)
   - On generate submit: POST to `/api/courses/generate` with `{ topic, skillLevel }` including `X-Requested-With: XMLHttpRequest` header. On 202 response: set `generationPhase: "generating"`, show `GeneratingCard`, add job to `useJobPoller`.
   - Handle 429 (limit or rate): show error via toast or inline message
   - Handle 503 (AI unavailable): show error
   - `useJobPoller` onComplete: extract `courseId` from `result.result.courseId`, redirect to `/courses/{courseId}` using `router.push()`. Also set `generationPhase: "complete"`.
   - `useJobPoller` onFailed: show error message, reset `generationPhase: "idle"`
   - Below generation area: render two `CourseSection` components:
     - "My Courses" section with `myCourses` (generated courses owned by user)
     - "Enrolled Courses" section with `enrolledCourses`
   - Stats summary (optional area above course sections): "X courses in progress", "Y lessons completed" -- derive from course data. No teacher stats.
   - Loading state: show skeleton cards while fetching
