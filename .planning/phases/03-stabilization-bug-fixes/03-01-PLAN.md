  <behavior>
    validateObjectId:
    - Returns null for a valid 24-char hex ObjectId string
    - Returns NextResponse with status 400 and error message for "not-an-id"
    - Returns NextResponse with status 400 for empty string
    - Custom label appears in error message: "Invalid Course ID" when label="Course ID"

    Enrollment model:
    - Creates enrollment document with course and student ObjectId refs
    - Compound unique index {course: 1, student: 1} prevents duplicate enrollment (second insert throws E11000)
    - Has enrolledAt field defaulting to Date.now
    - Has timestamps (createdAt, updatedAt)
    - Has index on {student: 1, enrolledAt: -1} for efficient "my courses" queries
    - Static method isEnrolled(courseId, studentId) returns boolean
    - Static method getEnrollmentCount(courseId) returns number

    getCoursePermissions:
    - Takes already-fetched ICourse document and JWTPayload (no DB call for course)
    - Queries Enrollment collection for isEnrolled (NOT course.enrolledStudents array)
    - Returns {isInstructor: true, canEdit: true, canView: true} when user is course instructor
    - Returns {isOwner: true, canEdit: true, canView: true} when user is course owner
    - Returns {isEnrolled: true, canView: true, canEdit: false} when user is enrolled
    - Returns {isAdmin: true, canEdit: true, canView: true} for admin users
    - Returns {isSharedWith: true, canView: true, canEdit: false} when user is in course.sharedWith
    - Returns all false flags for an outsider (not instructor, not owner, not enrolled, not admin, not shared)
    - canEdit is true when isInstructor OR isOwner OR isAdmin
    - canView is true when canEdit OR isEnrolled OR isSharedWith
  </behavior>
  <action>
    Write tests first for all three modules, then implement.

    validateObjectId (lib/utils/validateObjectId.ts):
    - Pure function taking (id: string, label?: string) => NextResponse | null
    - Uses mongoose.Types.ObjectId.isValid(id) for validation
    - Returns null for valid IDs (no error)
    - Returns NextResponse.json({ error: `Invalid ${label}` }, { status: 400 }) for invalid IDs
    - Default label is "ID"

    Enrollment model (lib/models/Enrollment.ts):
    - Mongoose schema with course (ObjectId ref "Course", required), student (ObjectId ref "User", required), enrolledAt (Date, default: Date.now)
    - Compound unique index: enrollmentSchema.index({ course: 1, student: 1 }, { unique: true })
    - Secondary index: enrollmentSchema.index({ student: 1, enrolledAt: -1 })
    - Export interface IEnrollment extends Document { course, student, enrolledAt, createdAt, updatedAt }
    - Static method isEnrolled: Enrollment.exists({ course: courseId, student: studentId })
    - Static method getEnrollmentCount: Enrollment.countDocuments({ course: courseId })
    - Use standard mongoose.models.Enrollment || mongoose.model() pattern

    getCoursePermissions (lib/auth/coursePermissions.ts):
    - Import Enrollment model, JWTPayload, ICourse
    - Export CoursePermissions interface: { isInstructor, isEnrolled, isOwner, isAdmin, isSharedWith, canEdit, canView }
    - Function signature: getCoursePermissions(course: ICourse, user: JWTPayload): Promise<CoursePermissions>
    - Check isInstructor: course.instructor.toString() === user.userId
    - Check isOwner: course.owner?.toString() === user.userId
    - Check isAdmin: user.role === "admin"
    - Check isSharedWith: course.sharedWith?.some(id => id.toString() === user.userId)
    - Check isEnrolled: await Enrollment.exists({ course: course._id, student: user.userId }) -- uses new Enrollment collection, NOT array
    - Derive canEdit: isInstructor || isOwner || isAdmin
    - Derive canView: canEdit || isEnrolled || isSharedWith

    Test files use mongodb-memory-server via existing helpers (connectTestDb, clearTestDb, disconnectTestDb).
    Unit tests for validateObjectId do not need DB connection.
    Integration tests for Enrollment and getCoursePermissions do.

    Register the Enrollment model in lib/models/index.ts barrel export.
  </action>
