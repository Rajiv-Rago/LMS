  <behavior>
    POST /quiz/start:
    - Returns 401 for unauthenticated user
    - Returns 400 for invalid course or assignment ObjectId
    - Returns 404 for non-existent course
    - Returns 404 for non-existent quiz assignment
    - Returns 403 for non-enrolled student
    - Returns 400 for unpublished quiz
    - Returns questions (without correctAnswer) and attempt info for enrolled student
    - Resumes existing incomplete attempt if one exists (does not create new)
    - Auto-closes expired attempt and starts fresh if time limit exceeded
    - Creates Submission document on first attempt

    POST /quiz/submit:
    - Returns 401 for unauthenticated user
    - Returns 400 when no active attempt exists
    - Returns 400 when attempt already submitted (completedAt set)
    - Returns 400 when time limit exceeded
    - Returns score, totalPoints, percentage, bestScore after grading
    - Includes detailed answers+questions when showCorrectAnswers enabled
    - Omits detailed answers when showCorrectAnswers disabled
    - Updates submission status to "graded", sets grade to bestScore

    GET /quiz (existing, stays in place):
    - Returns quiz info + attempts for enrolled student
    - Returns full assignment details for instructor/admin
    - Returns 403 for outsider
  </behavior>
