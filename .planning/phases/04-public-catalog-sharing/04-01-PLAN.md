    2. Add accessLevel field to courseSchema: `type: String, enum: ['restricted', 'unlisted', 'published'], default: 'restricted'`.
    3. Add enrolledCount field: `type: Number, default: 0`.
    4. Convert isPublished from a stored field to a Mongoose virtual: remove isPublished from the schema definition, add `courseSchema.virtual('isPublished').get(function() { return this.accessLevel !== 'restricted'; })`. Add `{ toJSON: { virtuals: true }, toObject: { virtuals: true } }` to schema options. Keep the `{ isPublished: 1 }` index as `{ accessLevel: 1 }` instead.
    5. Add index: `{ accessLevel: 1 }` and `{ enrolledCount: -1 }`.

    7. Update GET /api/courses/[id]: change `!course.isPublished && (!perms || !perms.canView)` to use getCoursePermissions with nullable user directly. Pass `user` (which may be null from authenticate()) directly to getCoursePermissions.
    8. Update GET /api/courses/[id]: change canEnroll to use `course.accessLevel !== 'restricted'` instead of `course.isPublished`.
    9. Update enroll route: change `!course.isPublished` check to `course.accessLevel === 'restricted'`. After successful Enrollment.create(), atomically increment: `await Course.findByIdAndUpdate(id, { $inc: { enrolledCount: 1 } })`. In DELETE (unenroll), after successful deleteOne, decrement: `await Course.findByIdAndUpdate(id, { $inc: { enrolledCount: -1 } })`.
    10. Update createTestCourse fixture: add `accessLevel` to overrides type.

    NOTE: isPublished is currently checked in GET /api/courses (the list route) as a query filter. Since isPublished becomes a virtual (not stored), queries filtering `{ isPublished: true }` will NOT work. The list route update is in Task 2. For the GET /api/courses/[id] route, the check is on the returned document object where the virtual works fine.

    IMPORTANT: When converting isPublished to a virtual, the existing `updateCourseSchema` in the PATCH handler accepts `isPublished` as a boolean. Update the PATCH handler: if `isPublished` is provided, map it to accessLevel (`true` -> 'published', `false` -> 'restricted'). This maintains backward compatibility.
