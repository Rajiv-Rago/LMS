# Evidence-based learner assessment

- Require at least three answered knowledge questions over two rounds before normal completion. Existing hard limits, skip and failure fallbacks still apply.
- Probe practical understanding and adjust follow-up difficulty using actual answers; focus syllabus teaching on demonstrated gaps and prerequisites.
- Keep unknown skills separate from proven gaps in fallback profiles.
- Include JSON limits in model instructions, allow a longer follow-up focus, and increase model deadlines to avoid premature fallback summaries.
- Allow retaking an assessment from a saved summary.
